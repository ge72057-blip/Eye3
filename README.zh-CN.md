# Eye 缩放控制器

[English](README.md) | 简体中文

一个悬浮小圆手柄，用来全屏放大手机任何界面。

## 操作

| 操作 | 效果 |
|---|---|
| 单击手柄 | 打开快捷面板（再单击或点面板外关闭） |
| 快速拖动手柄 | 移动手柄位置 |
| 长按不放再移动 | 在按下处平滑放大，画面按“跟手灵敏度”跟着手指走，松手恢复 |
| 双击 | 平滑放大并保持 |
| 放大后按住手柄并移动 | 同样按灵敏度跟手，松手保持放大 |
| 放大后再双击 | 恢复 |

放大状态下不能移动手柄、不能开面板，先双击恢复即可。按住期间手柄会隐藏，松手后原位出现；按住时可以用另一只手正常操作下面的界面（比如滑动列表）。灵敏度越高，手指动得越少画面走得越远，不用把手伸到屏幕边缘。

## 设置页（点桌面 Eye 图标）

- 状态：显示无障碍是否真的在运行，并带开启引导（含安卓 13 的“受限制的设置”）。
- 恢复：找回手柄（回默认位置、完全显示、闪烁提示、退出放大）；恢复所有设置。
- 调节：放大倍数、跟手灵敏度、变透明时间、透明度、手柄大小。
- 保活：电池不限制、自启动管理、最近任务锁定（按手机品牌给步骤）。
- 自启动：声明了开机广播，让 Eye 能出现在 vivo、小米等手机的“自启动管理”列表里；点按钮会直接打开本机的自启动页，打不开时显示手动步骤和失败原因。
- 可选自我修复：电脑上执行一次
  `adb shell pm grant com.eye.zoom android.permission.WRITE_SECURE_SETTINGS`
  之后系统关掉 Eye 时，打开本软件会自动重新开启。

## 用 GitHub 云编译

1. 在 GitHub 网页新建公开仓库，名字 `Eye`。
2. 解压本压缩包，把里面**所有内容**（包括 `.github` 文件夹）拖进仓库页面上传，点 Commit。
3. 打开仓库的 Actions 页面，等 "Build APK" 变绿（约 3-5 分钟）。
4. 点进这次运行，页面底部 Artifacts 里下载 `Eye-apk`，解压得到 APK。

## 安装与开启

1. 安装 APK，点桌面的 Eye 图标打开设置页，按状态卡片上的按钮前往无障碍设置。
2. 找到 Eye，打开开关，确认授权。
3. 安卓 13 及以上：如果开关是灰色，先到 系统设置 → 应用 → Eye → 右上角三点 → "允许受限制的设置"，再回来开。
4. 关闭系统自带的放大功能（无障碍 → 放大 / 放大手势、快捷方式），否则两者抢触摸。
5. 保活：设置页“让 Eye 不被系统杀掉”里有对应按钮和各品牌步骤。

## 文字与多语言

所有可见文字在 `app/src/main/res/values*/strings.xml`：
英语 `values`，简体 `values-b+zh+Hans`，繁体 `values-b+zh+Hant`。
加语言：复制 `values` 里的文件，翻译后放进新文件夹（如日语 `values-ja`），不用改代码。
